## MODIFIED Requirements

### Requirement: Operational behavior is documented
The system SHALL document current available behavior, supported media formats, unverified username/session access, persisted state lifecycle, and explicitly deferred capabilities.

#### Scenario: Product expectation setting
- **WHEN** a stakeholder reviews operational docs at a phase boundary
- **THEN** available behavior and intentionally absent playlist/playback/refresh integration are distinguished

#### Scenario: Access scope is reviewed
- **WHEN** a stakeholder reviews access constraints
- **THEN** documentation explains instance sessions, stable users, no credentials/authenticated ownership, inactivity expiration, and media presentation
